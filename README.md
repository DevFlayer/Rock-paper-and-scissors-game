# 🎮 Building Rock-Paper-Scissors in C++: My Logic & Thought Process

This project is a functional implementation of the classic **Rock-Paper-Scissors** game, developed in **C++**. The primary goal was to practice core programming logic, standard libraries, and randomness handling.

The inspiration for this project came from a job interview challenge I watched (originally in Java), which I decided to replicate and adapt using C++ to strengthen my fundamentals.

## 🚀 Features & Technical Highlights
- **Randomness Logic:** Implemented using `std::vector` and `std::shuffle` to handle the CPU's moves, ensuring unpredictable and fair gameplay [00:00:22].
- **Clean Logic Flow:** Focused on keeping the code functional, efficient, and easy to read.
- **Daily Coding Challenge:** This project is part of my personal commitment to post at least one project per day, documenting my growth as an aspiring Computer Engineer [00:00:42].
